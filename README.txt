EE Study Bench: installable web app (no Mac needed)
===================================================

This folder is a complete offline web app. To put it on an iPhone home screen:

1. Host the folder on any HTTPS site. Free options:
   - Netlify Drop: open https://app.netlify.com/drop in a browser and drag this whole folder onto the page.
   - GitHub Pages: create a repository, upload these files, then Settings > Pages > Deploy from branch.
2. On the iPhone, open the site's address in Safari.
3. Tap the Share button, then "Add to Home Screen", then "Add".

It then opens full screen from its own icon, without the Safari bars, and keeps working with no
internet connection after the first visit. Progress is saved on the phone.
